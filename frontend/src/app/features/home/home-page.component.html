Design notes

Quiet Wealth theme

The interface now leans on restrained contrast, serif display moments, and soft glass surfaces instead of generic blue admin styling.

Typography

Manrope for body copy, Cormorant Garamond for key headings.

Palette

Soft stone backgrounds, deep evergreen actions, and muted gold highlights.

Mode support

Light and dark themes share the same tone, with dark mode staying warm rather than neon.
